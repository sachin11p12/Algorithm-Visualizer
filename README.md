# Algorithm Visualizer

An interactive **Algorithm Visualizer** built with **Next.js 15**, **React 19**, **TypeScript**, and **Tailwind CSS** to help users understand **Sorting** and **Searching** algorithms through smooth animations and real-time execution.

## Features

* 📊 Sorting: Bubble, Selection, Insertion, Merge, Quick, Heap
* 🔍 Searching: Linear & Binary Search
* ⏯️ Play, Pause, Resume, Step Forward/Backward, Reset
* ⚡ Adjustable animation speed (0.25×–4×)
* 📈 Live statistics (Comparisons, Swaps, Steps, Time)
* 📝 Synchronized pseudocode highlighting
* 🎨 Responsive UI with Dark/Light mode
* 🎯 Custom array & search target input

## Tech Stack

* Next.js 15 (App Router)
* React 19
* TypeScript
* Tailwind CSS
* Zustand
* Framer Motion
* Lucide React
